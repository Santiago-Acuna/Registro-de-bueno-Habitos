## Description

Extract form logic from `createHabit.tsx` into a reusable custom hook. This hook will encapsulate all form state management, validation logic, and submission handling, making the form component cleaner and the logic reusable.

## Subtasks

- [ ] Create `src/hooks/useHabitForm.ts`
- [ ] Extract `useState` logic for habit, errors, disabled
- [ ] Move `handleChange` validation logic to hook
- [ ] Move `handleSubmit` logic to hook
- [ ] Add TypeScript types for hook return values
- [ ] Export hook from `index.ts`

## Files to Create/Modify

- `src/hooks/useHabitForm.ts` (create)
- `src/hooks/index.ts` (modify)

## Implementation Notes

The hook should return an object with:

- Form state (habit data, errors, disabled state)
- Form handlers (handleChange, handleSubmit)
- Any derived state or validation functions
