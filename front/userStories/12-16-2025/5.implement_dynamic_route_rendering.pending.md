# US-005: Implement Dynamic Route Rendering in App.tsx

**Priority:** High
**Complexity:** Medium
**Estimated Time:** 2.5 hours
**Dependencies:** US-001, US-002, US-003, US-004

## User Story

As a frontend developer, I want to replace static routes with dynamic route generation so that routes are automatically created based on backend configuration.

## Description

Refactor App.tsx to fetch routes from the backend on application startup and dynamically generate Route components based on the configuration. The root route "/" must remain static, while all habit-specific routes are generated dynamically.

## Acceptance Criteria

**Given** the application loads
**When** App.tsx mounts
**Then** it should:
- Fetch routes from backend using useRoutes hook
- Keep root "/" route static with CreateHabits and HabitsSelection
- Generate dynamic routes for each habit from backend config
- Show loading state while fetching routes
- Show error message if fetching fails

**Given** routes are successfully fetched
**When** routes are rendered
**Then** each route should:
- Map to correct component from Pages barrel export
- Use path from backend configuration
- Handle invalid component names gracefully
- Not override the static root route

**Given** a user navigates to a dynamic route
**When** the route matches a habit path
**Then** the correct habit component should render

**Given** the backend is unavailable
**When** route fetching fails
**Then** show error UI with retry option

## Technical Implementation

### App.tsx Structure
```typescript
import * as Pages from "./components/Pages";
import { useRoutes } from "./hooks/useRoutes";

type PageComponentName = keyof typeof Pages;

const App: React.FC = () => {
  const { routes, isLoading, error, fetchRoutes } = useRoutes();

  useEffect(() => {
    fetchRoutes();
  }, [fetchRoutes]);

  if (isLoading) return <LoadingComponent />;
  if (error) return <ErrorComponent error={error} onRetry={fetchRoutes} />;

  return (
    <BrowserRouter basename="/">
      <div className={styles.container}>
        <Routes>
          {/* Static root route */}
          <Route path="/" element={[<CreateHabits />, <HabitsSelection />]} />

          {/* Dynamic routes */}
          {routes.map((route, index) => {
            const Component = Pages[route.component as PageComponentName];
            if (Component) {
              return <Route key={index} path={route.path} element={<Component />} />;
            }
            return null;
          })}
        </Routes>
      </div>
    </BrowserRouter>
  );
};
```

### Loading Component

// Simple loading indicator

### Error Component
```typescript
// Error display with retry
function ErrorComponent({ error, onRetry }: { error: string; onRetry: () => void }) {
  return (
    <div className={styles.error}>
      <Typography color="error">{error}</Typography>
      <Button onClick={onRetry}>Retry</Button>
    </div>
  );
}
```

## Edge Cases

- Backend returns empty routes
- Backend returns malformed route data
- Component name doesn't exist in Pages
- Duplicate route paths
- Invalid paths (not starting with /)
- Slow network (timeout handling)
- User navigates before routes load
- Race condition: multiple fetchRoutes calls

## Validation Rules

- Root route "/" must always be static
- Dynamic routes must not override root route
- Each route must have valid path and component
- Component names must exist in Pages barrel export
- Route keys should be stable (use index for now)
