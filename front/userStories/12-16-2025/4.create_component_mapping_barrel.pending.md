# US-004: Create Component Mapping Barrel Export

**Priority:** High
**Complexity:** Small
**Estimated Time:** 1 hour
**Dependencies:** None

## User Story

As a frontend developer, I want a barrel export for route components so that dynamic routes can map component names to actual component implementations.

## Description

Create a centralized barrel export file that exports all components that can be used as route destinations. This allows dynamic route rendering to map string component names from the backend to actual React components.

## Acceptance Criteria

**Given** dynamic routes need to render components
**When** a route specifies a component name as a string
**Then** the component mapping should:

- Export all route-eligible components from a single file
- Use named exports matching the component names from route config
- Include all existing route components (ComplexHabits, ReadingDashboard, Books)
- Be easily extensible for new components

**Given** a new habit component is added
**When** it needs to be available for dynamic routing
**Then** it should only need to be added to the barrel export

## Technical Implementation

### Component Mapping Structure

```typescript
// front/src/components/Pages.ts
export { default as ComplexHabits } from "./complex habits/complex-habits";
export { default as ReadingDashboard } from "./reading/reading";
export { default as Books } from "./reading/book/books";
export { default as SimpleHabits } from "./simple-habits/simple-habits"; // Future
export { default as WithoutIntervalsHabits } from "./without-intervals/without-intervals"; // Future
```

### Usage Pattern

```typescript
import * as Pages from "./components/Pages";

// Map string to component
const Component = Pages[route.component as PageComponentName];
```

### Files to Create

- `front/src/components/Pages.ts` - Barrel export

### Files to Modify

- None (new file only)

## Test Requirements (TDD - RED Phase)

### Unit Tests (`Pages.test.ts`)

1. **Export Existence Test**
   - Should export ComplexHabits
   - Should export ReadingDashboard
   - Should export Books
   - All exports should be React components

2. **Component Type Test**
   - Each export should be a valid React component
   - Should have displayName or name property

3. **No Default Export Test**
   - Should not have default export
   - All exports should be named

4. **Import Test**
   - Should be importable with `import * as Pages`
   - Should be importable with named imports
