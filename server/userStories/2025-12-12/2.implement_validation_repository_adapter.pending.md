## Technical Notes

**Database Schema Context:**
```prisma
model GlobalEntityIdentifiers {
  id         String   @id @default(uuid())
  name       String
  icon       String
  entityType String   // 'habit' or 'action_type'
  entityId   String   // FK to habits.id or actionTypes.id

  habits     Habits?      @relation(...)
  actionTypes ActionTypes? @relation(...)
}
```

**Query Pattern for Global Uniqueness (Habits):**
```typescript
await prisma.globalEntityIdentifiers.findFirst({
  where: {
    name: name,
    entityType: 'habit',
    ...(excludeEntityId && { entityId: { not: excludeEntityId } })
  },
  select: { id: true }
});
```

**Query Pattern for Per-Habit Uniqueness (ActionTypes):**
```typescript
await prisma.globalEntityIdentifiers.findFirst({
  where: {
    name: name,
    entityType: 'action_type',
    actionTypes: {
      habitId: habitId
    },
    ...(excludeEntityId && { entityId: { not: excludeEntityId } })
  },
  select: { id: true }
});
```

**Testing Strategy:**
- Use in-memory mock for PrismaService
- Test boundary conditions (empty results, multiple results)
- Verify filter combinations work correctly
- Ensure proper type handling for optional parameters
