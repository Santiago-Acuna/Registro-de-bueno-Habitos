# US-002: Remove Orphaned Global Entity Identifiers Module

**As a** Backend Developer
**I want to** remove the unused GlobalEntityIdentifiers module
**So that** the codebase is clean and free of dead code

## Problem Statement

The `global-entity-identifiers` module exists but is completely orphaned:
- Not imported in `AppModule`
- Not used by `HabitsModule` or `ActionTypesModule`
- Repositories create global identifiers directly via Prisma instead

This module was meant to centralize validation logic, but we've decided on a simpler approach:
- Database constraints enforce uniqueness
- Enhanced error messages provide user-friendly feedback
- No duplicate validation logic needed

## Rationale

**Why delete instead of use?**
1. **Database constraints already enforce uniqueness** - No need for application-layer validation
2. **Error messages now user-friendly** - P2002 errors properly handled
3. **Simpler is better** - Direct Prisma calls are straightforward
4. **YAGNI principle** - Don't maintain code we don't use
5. **Reduced complexity** - Fewer layers means easier maintenance

**Current flow (works well):**
```
Controller → Service → Repository → Prisma → Database (enforces constraints)
                                              ↓ (if error)
                                    HttpExceptionFilter (user-friendly messages)
```

**Unused flow (being deleted):**
```
GlobalEntityIdentifiersService (unused)
GlobalEntityIdentifiersRepository (unused)
```
